🏡 Capstone Project: House Price Predictor (Multiple Linear Regression)

I developed and deployed an end-to-end Machine Learning web application that predicts residential property prices using a Multiple Linear Regression (MLR) model trained on a real-world King County housing dataset (4,551 verified sales).

🎯 How This Project Helps Users:
1️⃣ Enables Buyers to estimate fair property valuations and verify whether asking prices are justified before committing offers.
2️⃣ Assists Sellers in setting realistic, competitive listing prices and measuring ROI on renovations (adding bathrooms, finishing basements).
3️⃣ Helps Real Estate Agents generate instant, data-driven Comparative Market Analysis (CMA) reports.
4️⃣ Saves Time by replacing hours of manual comps research with instant multi-variable predictive modeling.
5️⃣ Improves Transparency with fully explainable regression coefficients and mathematical formulations (OLS hyperplane).

📊 Model Architecture & Test Evaluation (20% Holdout Split):
• Algorithm: Scikit-Learn Ordinary Least Squares (OLS) Linear Regression Pipeline
• Features: Living Area, Lot Size, Bedrooms, Bathrooms, Floors, Waterfront, View, Condition, Basement, Age & City Location Encoding
• R² Score: 0.676 (Explains 67.6% of property price variance)
• MAE: $131,870 (A 45.8% error reduction vs naive baseline)
• RMSE: $219,399
